# 梅花易數 Grandmaster Skill

## 1. 核心原則
- **確定性計算 (100% Deterministic Code)**：主卦、動爻、互卦、變卦、體用、五行生剋完全由演算法計算，嚴禁 LLM 自行心算。
- **權威離線知識 (Authoritative Knowledge Base)**：內建完整的先天八卦、周易 64 卦卦辭、384 爻辭、八卦萬物類象與體用總訣。
- **三層架構分離**：`CALCULATE -> LOOKUP -> INTERPRET`，確保同一輸入永遠得出完全相同的卦象結果。

## 2. 起卦方式支援
1. **數字起卦**：支援 2 個數字（以兩數之和求動爻）或 3 個數字（第三數為動爻）。
2. **隨機數字起卦**：由系統產生隨機 3 個數推演。
3. **時間起卦**：以年月日時干支數值（農曆/時辰）推演，同一時辰結果確定唯一。

## 3. 解讀規範
- 嚴格遵守防幻覺規範，僅引用上下文提供的經文原文。
- 依固定結構輸出：起卦資料 -> 主卦現狀 -> 體用五行 -> 動爻啟發 -> 互卦過程 -> 變卦趨勢 -> 綜合判讀 -> 現實建議。
